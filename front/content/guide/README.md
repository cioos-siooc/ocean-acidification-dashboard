# OceanECO user guide

OceanECO maps the ocean chemistry and physics of the Salish Sea from the SalishSeaCast model, alongside sensor
measurements from Ocean Networks Canada, ORCA and others. This guide explains every part of the dashboard, one topic
per page. Each page stands on its own, and each has a short captioned video showing the same steps.

Open the dashboard at **https://oceaneco.cioospacific.ca**.

## Where things are

- **Left panel:** **Field** (what the map shows), **Depth**, and the sensor list.
- **Map:** the model's values at one depth and one time. The toolbar runs down its left edge.
- **Vertical profile** (top right): the water column at the point you clicked.
- **Bottom panel:** the timeseries chart and its **Model depth**, **Sensor depth** and **Cross-Section** tabs,
  with the dates, the time controls and **Download**.
- **Top bar:** **Share** and the data server status.
- **Full-screen workspaces:** **Comparison** (model against a sensor) and **Analysis** (the long record at a point).

## Words used in this guide

| Term | Meaning |
|---|---|
| **Field** | The variable on the map, such as Temperature, Salinity, pH or Omega Aragonite. |
| **Model** | SalishSeaCast, a computer model of the Salish Sea run every day. It gives values everywhere, at every depth, from 2007 to now. |
| **Sensor** | A real instrument in the water: a buoy, a seabed platform or a profiler. |
| **Climatology** | What is usual for a date: the lowest, average and highest values on that date in every year since 2007. |
| **pH** | Acidity. Lower pH is more acidic. |
| **Omega (Ω)** | Saturation state for the minerals shells are made of (aragonite or calcite). Below 1, seawater is corrosive to shells. |
| **DIC** | Dissolved Inorganic Carbon: the total carbon dioxide dissolved in the water. |
| **Total Alkalinity** | The water's capacity to buffer acid. River water is low, seawater high. |
| **1H / 1D / 1M** | Hourly, daily and monthly values. |
| **DJF, MAM, JJA, SON** | Winter (Dec–Feb), spring (Mar–May), summer (Jun–Aug) and autumn (Sep–Nov). |

The numbers in the worked examples were read from the dashboard in November 2026. The model updates every day, so
recent values may differ slightly when you try them.
